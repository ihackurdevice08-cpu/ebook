문제 선정부터 교차 검증까지 각 단계의 순서와 의도, 사용한 스킬과 프롬프트, 수정 전후를 정리했습니다.

작업 진행 의도

방법 선택부터 결과 검증까지 다섯 단계를 직접 진행했고, 단계마다 어떤 의도로 무엇을 했는지 적었습니다.

방법 결정분석 방법을 직접 선택
분석 실행·보완코드 실행과 분석 보강
보고서 작성·수정보고서와 영상 완성

01

문제 선정

  • 데이터 분석으로 문제를 해결하는 과정이 잘 드러나고 다른 학생과 겹칠 가능성이 낮도록, 문제집 5개 중 P1(물류센터 인력 수요 예측·배치)을 선택
02

방법 결정

  • 방법 선택은 직접 하고 코드 작성은 AI에 맡기도록, 데이터 설명과 10행 샘플만 주고 가능한 분석 방법을 제안받아 사용할 방법을 직접 선택
  • 시계열 데이터의 누수를 막도록, 당일 결과 변수는 예측 변수로 쓰지 않게 명시
  • 실행이 간단하도록, 선택한 방법 전체를 파이썬 파일 하나로 받음
03

분석 실행·보완

  • 결과를 직접 확인하도록, 받은 코드를 Antigravity에서 직접 실행
  • 결론에서 약한 재배치 효과와 검증 기간 편중을 보강하도록, 요일·날씨별 출고율, 미처리 물량과 잔업, 센터 간 재배치, 검증 구간 2개, 보정 계수 탐색을 추가
04

보고서 작성·수정

  • 하나의 이야기로 읽히도록, 문제·원인·해결·효과·비용·운영·결론 순서의 개조식으로 쓰고 한 장에는 한 가지 아이디어만 담도록 지시
  • 처음 보는 사람도 이해하도록, SLA·UPH 같은 약어를 출고율과 시간당 처리량으로 풀어 쓰도록 지시
  • 결론이 과장되어 보이지 않도록, 한계는 짧게 쓰고 센터 간 이동은 "일부 센터만 부족한 날의 보조 수단"으로 바꾸도록 지시
  • 문장이 자연스럽게 읽히도록, 단어와 호응은 직접 읽으며 수정
  • 보고서를 읽지 않은 사람도 같은 결론을 이해하도록, 같은 메시지로 영상을 만들도록 지시 (영상 기획 의도에 정리)
05

교차 검증·반영

  • 한 AI의 환각을 다른 AI로 걸러내도록, 분석 결과와 프롬프트를 다른 AI(GPT)에 주고 코드를 다시 실행해 핵심 수치를 새로 계산하게 함
  • 지적받은 내용이 실제로 맞는지 가리도록, 원본 데이터로 직접 다시 계산해 확인
  • 숫자 오류는 없었고 단위와 범위 표현만 수정 (수정 전후는 아래 검증과 수정에 정리)
사용한 스킬

스킬은 같은 종류의 작업을 같은 기준으로 반복하도록 만든 지침 묶음입니다. 앞의 다섯 가지는 이 과제 이전에 직접 만들어 둔 것입니다.

사용한 프롬프트

대화 전체가 아니라 단계별로 사용한 지시의 요지를 정리했습니다.

분석 방법 결정

데이터 설명 파일과 10행 샘플을 주고 가능한 분석 방법, 사용 변수, 알 수 있는 내용을 제시하게 했습니다. 시계열 데이터의 누수에 주의하게 하고, 당일 결과 변수는 예측 변수로 쓰지 않도록 명시했습니다.

분석 코드 생성

선택한 분석 방법 전체를 하나의 파이썬 파일로 실행하게 하고, 결과표·그림·요약을 정해진 폴더에 저장하게 했습니다.

보고서 생성

분석 결과(표, 그림, 요약)를 바탕으로 쿠팡 물류센터 인력 수요 예측·배치 분석 보고서를 작성한다.
구성: 문제, 원인, 해결안, 효과, 비용, 운영, 결론 순서. 각 장은 한 가지 아이디어만 다룬다.
문체: 개조식(명사형 종결, 짧은 구). 한 문장에는 판단 하나만 담는다.
용어: SLA, UPH 같은 약어 대신 출고율, 시간당 처리량처럼 쉬운 우리말로 풀어 쓴다.
수치: 분석 결과 파일에 있는 값만 쓰고, 계산한 수치는 자체 계산이라고 밝힌다. 한계는 짧게 쓴다.

영상 제작

보고서 전체 내용을 담은 얼굴 없는 2D 설명 영상을 만든다. 나레이션 없이 자막과 직접 합성한 배경음악만 쓴다.
먼저 영상 전체 메시지 한 문장, 장면별 메시지, 장면마다의 자막과 화면 수치를 확정해 보여 준다. 확정 전에는 제작하지 않는다.
자막은 보고서 문장을 그대로 옮기지 않고, 설명 영상 대본처럼 이야기 흐름에 맞춰 쓴다.
택배 박스가 움직이는 장면과 숫자·그래프를 한 화면에서 함께 보여 준다. 불필요한 글자 효과는 넣지 않는다.

교차 검증

다른 AI(GPT)를 독립 검토자로 두고, 코드를 다시 실행해 핵심 수치를 새로 계산한 뒤 보고서와 대조하게 했습니다. 확인된 오류와 의견은 구분해 표로 제출하게 했습니다.

검증과 수정

다른 AI의 지적을 하나씩 원본 데이터로 다시 계산해 확인했고, 숫자 해석이 실제와 다른 부분만 고쳤습니다. 숫자(317, 2,413, 90.5%, 89.0% 등)와 결론(인건비 1.8% 증가, 프로모션 출고율 89.32%에서 99.21%로 상승)은 그대로 두고 단위와 범위 표현만 바꿨습니다.
