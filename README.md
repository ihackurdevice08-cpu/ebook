# PDF 리더

PDF를 올려 읽는 브라우저 리더입니다. 서버에 파일을 보내지 않고 브라우저 안에서만 처리합니다.

- 책꽂이, 이어 읽기, 진행률
- 북마크, 형광펜, 밑줄, 메모, 쪽 메모
- 전체 검색, 목차, 썸네일, 한 쪽·두 쪽·스크롤 보기
- 영영·한글 사전, 단어장 (인터넷 연결 필요)

데이터는 접속한 브라우저에 저장됩니다. 기기를 옮길 때는 보기 설정의 백업을 사용하세요.

## 라이선스

이 저장소에는 [PDF.js](https://github.com/mozilla/pdf.js)(Apache License 2.0)가 포함되어 있습니다.
